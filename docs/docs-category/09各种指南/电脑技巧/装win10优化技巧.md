## 为什么这套机器非常适合 LTSC2019（X79 洋垃圾平台）

1. **砍掉应用商店、UWP、小娜，后台占用低**；待机内存一般占用 1.4‑2.3G，对比普通专业版 2.5‑3.5G，32G 内存下后台资源更宽裕，适合虚拟机挂机、剪辑。
2. **没有强制功能性大版本升级**，只接收安全补丁，老 X79 国产主板不容易升级之后蓝屏翻车。
3. ❗**注意：原版 LTSC2019 不带 Edge 浏览器！安装完之后需要自己下载 Chrome/Edge**。
4. 该系统支持最大内存：**2TB，32G 完全识别无压力**。

## ⚠️X79 平台安装前 BIOS 设置（非常关键，防止蓝屏 IRQL 错误）

> 
> 国产 X79 主板（华南 / 铭速等）

1. 启动模式：**优先 Legacy BIOS (MBR) 安装；不要硬上 UEFI（很多国产 X79 的 UEFI 固件 bug 多，容易蓝屏）**
2. CPU 电源选项：**关闭深度 C‑state（C6 休眠）**，Xeon E5 V2 系列开 C6 很容易随机蓝屏死机；保留睿频打开。
3. 内存：ECC 内存，BIOS 里面 ECC 可以关闭；优先跑四通道。
4. Secure Boot 直接关闭（LTSC2019 不需要安全启动）Microsoft ...。

## 📌安装介质制作

用 Rufus 写入 U 盘；**分区方案 MBR，目标系统类型 BIOS (非 UEFI)**，不要 Gpt‑UEFI（国产 X79 坑多）。

> 
> 不要用各种修改版精简 Ghost 系统，就用你说的 DVD 原版 ISO。

## 🛠装好系统之后第一件事：安装驱动（X79 重点！）

> 
> 不要直接用驱动精灵一键打全套！容易装服务器版驱动直接蓝屏。

1. 先装**主板 X79 芯片组驱动（主板光盘 / 官网）**
2. 再装独立显卡驱动（N 卡 / A 卡官网下载，不要公版服务器驱动）
3. 声卡、网卡；

> 
> X79 老平台网卡经常出现 100% 磁盘占用，网卡驱动优先主板厂商版本，不要微软通用驱动。
